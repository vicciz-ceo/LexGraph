# Sprint: Puerto Rico — Spanish-language definition rules

## Mandate

Recon finding (dossier §6, B3b): the US-PR corpus (23,636 rows) is in
SPANISH and was 100% invisible to the English-only USProfile — 633 real
`Definiciones` headings undetected. This sprint builds PR's Spanish rule
set (headings, definition idioms, entry markers, scope phrases, citation
grammar) as `USProfile`-hosted rule modules behind the core seam. The
recon's sampled idiom counts were a LEAD; the measured survey is archived
in the log. Example row: `STATE_PR_LEY_249_2003_ART3`.

## Acceptance gates (program manager-defined)

- **P1 — Real PR statutes parse**: `Definiciones` sections are detected and
  their terms extracted, RED tests from real PR rows before implementation.
- **P2 — Spanish definition idioms are captured** (`significa`,
  `se entenderá por`, quoted-term appositions as found in the corpus),
  including definitions outside canonical Definiciones sections.
- **P3 — Scope stamped/enforced** for Spanish scope phrases
  (`A los fines de este Artículo…` → article scope, etc.) via the core
  seam, live-path both directions.
- **P4 — Zero-miss sweep (director bar)**: QA sweeps the full PR file for
  Spanish definition signals; every hit captured or proven
  not-a-definition. Report the before/after capture rate (before = 0).
- **P5 — Nothing regresses**: English-state behavior untouched (PR rules
  must not fire on English text); all existing tests green; P-R2 on
  precision conflicts.
