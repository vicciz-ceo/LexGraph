# Sprint: Puerto Rico — Spanish-language definition rules

## Mandate

Recon finding (dossier §6, B3b): the US-PR corpus (23,636 rows) is written
in SPANISH and is 100% invisible to the English-only USProfile. ~529 real
`Definiciones` headings (`is_definitions_heading("Artículo 3. Definiciones")`
→ False, verified live); Spanish drafting idioms measured in a 4,000-row
sample: `significa` 1,006, `A los fines de` ("for purposes of") 261,
`se entenderá por` ("shall be understood as") 26. This sprint builds the
Spanish rule set for PR — headings, definition idioms, entry markers,
scope phrases (`A los fines de este Artículo/Capítulo…`), and citation
grammar as found in the real corpus — as its own profile or rule-module set
behind the core seam. Example row: `STATE_PR_LEY_249_2003_ART3`.

## Acceptance gates (program manager-defined)

- **P1 — Real PR statutes parse**: `Definiciones` sections are detected and
  their terms extracted, RED tests from real PR rows before implementation.
- **P2 — Spanish definition idioms are captured** (`significa`,
  `se entenderá por`, quoted-term appositions as found in the corpus),
  including definitions outside canonical Definiciones sections.
- **P3 — Scope stamped/enforced** for Spanish scope phrases
  (`A los fines de este Artículo…` → article scope, etc.) via the core
  seam, live-path both directions.
- **P4 — Zero-miss sweep (director bar)**: QA sweeps the full PR file for
  Spanish definition signals; every hit captured or proven
  not-a-definition. Report the before/after capture rate (before = 0).
- **P5 — Nothing regresses**: English-state behavior untouched (PR rules
  must not fire on English text); all existing tests green; P-R2 on
  precision conflicts.

## Coordination

Core sprint owns scope plumbing + registry; read its `## Seam spec` from
branch `claude/defs-core-scope`; merge after core. Whether PR is a distinct
profile class or a rule-set under USProfile is a SEAM question — the Planner
proposes, the core Planner reviews, disagreement escalates to the program
manager. The recon Spanish-idiom inventory is a LEAD, not a complete
grammar: the Planner does its own corpus-driven idiom survey before
freezing item scope. Registry registrations append-only. Out-of-family
misses route via program manager.
