# Sprint: Israel — definition completeness on the full corpus

## Mandate

From the program (read `design_sections` first — do not re-derive recon):
every definition in Israeli law is captured, including definitions living
outside canonical הגדרות sections, with correct scope; scoped definitions
assert only within their scope; completeness measured on the FULL
israeli-laws-wiki corpus (director decision 4), not fixtures.

Recon (dossier §3): 6,133 laws, `data/laws/*.wiki` + `.meta.json`, 168 MB.
Confirmed-missed classes at sprint start: (a) `בפרק/בסימן/בחלק זה` scoped
definitions; (b) 3-word `לענין/לעניין סעיף זה` variants; (c) ad-hoc
`(בפרק זה - X)` markers; (d) prose-body definition sections yielding [].
Per-class counts and live re-confirmations are in the log.


## Acceptance gates (program manager-defined)

- **I1 — The whole Israeli corpus loads.** All 6,133 laws ingest through one
  documented command with a measured report (rows, per-file failures, wall
  time, peak memory) — the same standard as the US 2,045,897-row run. The
  corpus directory is READ-ONLY; never modify the POC folder.
- **I2 — The four missed classes are captured** (a-d above), each with RED
  tests built from real corpus rows before implementation.
- **I3 — Scoped definitions assert only within their scope** on the real
  corpus, proven live-path in both directions, including סימן/פרק/חלק units
  and the סעיף-level variants.
- **I4 — Zero-miss sweep (director bar).** QA adversarially sweeps the full
  corpus for definition signals; every hit is either captured or proven
  not-a-definition. Any confirmed miss fails the gate.
- **I5 — Nothing regresses.** All 167 existing IL tests green unchanged;
  false-positive conflicts escalate per P-R2 rather than being traded away
  silently.
